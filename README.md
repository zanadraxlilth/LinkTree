# ZX Streetwear linktree

- `index.html` is the full page (logo and wordmark are built in, nothing else needed).
- `logos/` has the web-ready logo, wordmark and icon files for other uses.

## Publish on GitHub Pages
1. Upload everything in this folder to a new GitHub repo.
2. Settings > Pages > Deploy from a branch > `main` / root > Save.
3. Your site goes live at `https://<username>.github.io/<repo-name>/`.
